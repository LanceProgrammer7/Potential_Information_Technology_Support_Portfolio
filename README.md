## Support Methodology
I use a structured support process:
1. Define and record the issue.
2. Gather information from the user and affected system.
3. Reproduce the problem when possible.
4. Identify likely causes.
5. Test solutions in a controlled order.
6. Apply the appropriate fix.
7. Confirm that the issue is resolved.
8. Document the solution and any follow-up steps.
